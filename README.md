# METEO365（プロトタイプ）

即売会イベント・印刷所の入稿締切・イラストの仕事の納期・支援サイトの投稿を **ひとつのカレンダーで** 管理する、個人用のウェブアプリです。
iPhone での利用を第一に設計しています（ビルド不要・オフライン動作・データは端末内に保存）。

## できること

### 案件の管理
次の3種別を同じ画面で管理します。

| 種別 | 主な項目 | 締切の呼び名 |
|---|---|---|
| 即売会 | イベント日・会場・スペース・印刷所の入稿プラン | 入稿締切 |
| 仕事 | クライアント・報酬 | 納品日 |
| 支援サイト | サイト（pixivFANBOX / Fantia / Ci-en / Patreon のプリセットあり）・プラン | 公開日 |

- 支援サイトは投稿ごとに内容が変わるため、**案件ごとに漫画・イラストを選べます**（選んだ内容に応じて基本タスクが切り替わります）
- 内容は **漫画 / イラスト** から選び、対応する基本タスクが自動で作られます
  - 漫画：プロット → ネーム → 下書き → 線画 → 仕上げ
  - イラスト：ラフ → 下書き → 線画 → 下塗り → 塗り → 仕上げ
- 仕事のときは **デザイン** も選べます（工程が案件ごとに違うため基本タスクは空。設定画面で自分の工程をテンプレート登録できます。数量は「点数」で数え、範囲は「2〜3点目」と表示します）
- タスクは自由に追加・削除・並べ替え・リネームでき、テンプレート自体も設定画面で編集できます

### 作業開始日
案件ごとに **作業開始日** を指定します。ここを起点に、締切までの稼働日へ各タスクの期間と1日のノルマが配分されます。

- 新規作成時に指定でき、**後からいつでも変更できます**（案件詳細の「作業開始日 ◯/◯ → ◯/◯」の行をタップ、または案件の編集画面）
- 変更すると **各タスクの期間と1日のノルマが自動で計算し直されます**（記録済みの実績はそのまま残り、手動で固定したノルマは自動配分に戻ります）
- 締切を変えたときも同じように再計算されます

### 1日ごとのノルマ自動計算（このアプリの中心機能）
合計ページ数（またはカット数）と作業期間を指定すると、**1日あたりのノルマを自動で割り振ります**。

> 例）合計30ページの漫画で「下書きを 5/12〜5/20 にやる」と設定
> → 9日間に 3P / 3P / 4P / 3P / 3P / 4P / 3P / 3P / 4P（合計30P）と自動配分
> → 予定には **「下書き 1〜3P」「下書き 4〜6P」…** と、その日に進めるページ範囲が入ります

- **その日に進める範囲**（例：`下書き 5〜8P` / イラストなら `2〜3枚目`）をカレンダー・日別・タスク・.ics のすべてに表示します。休みを挟んでも通し番号は連続します
- **休業日**にした日は自動的に飛ばして、残りの日に配り直します。休業日はカレンダーの日別画面で指定します（設定画面には項目を置いていません）
- 割り当て後に休みを増やしてタスクの期間に収まらなくなったときは、**未完了の工程を「今日〜締切」の稼働日へ組み直すか確認します**（そのままだと1日のノルマだけが増えてしまうため）。案件詳細の「未完了の工程を今日から組み直す」からいつでも実行できます
- 期間内がすべて休みになったタスクは、勝手に休みへ割り当てずに警告します
- 特定の日のノルマは手で固定でき、その差分は他の日へ自動で再配分されます
- 実績を記録すると **遅れ量** と **これから必要な1日あたりのペース** を表示します
- 「残りを再配分」で、遅れたぶんを今日以降にならし直せます
- 日別画面の「⋯」から **できなかった → 翌日以降に回す** をワンタップで実行できます
- **任意の日・任意のタスクに実績を追加**できます（前倒しで進めた分、予定外の日に描いた分も記録できます）

### 名義で切り替える（2つの活動を1つのアプリで）
案件そのものに**どちらの名義の仕事か**を持たせられます。名義を2つ以上登録すると、画面右上に**名義の切り替えボタン**が出ます。

- 選んだ名義の案件だけを **ホーム・カレンダー・案件一覧・アラート・集計** に表示します
- **名義を割り当てていない案件は、どの名義を選んでいても表示します**（取りこぼし防止）
- 名義ごとに**識別色**を設定でき、案件一覧や切り替えボタンで目印になります
- 案件に名義を設定しておくと、その案件の請求書・領収書の**発行元が自動で選ばれます**
- 新しい案件を作るときは、**そのとき見ている名義**が初期選択されます

### 売上（下タブ）
下のタブの **「売上」** から開きます。発行した書類を年・月・名義で横断集計します。

- **請求書を「発行済み」にした時点で売上として数えます**（下書きは数えず、別枠で「下書き ◯件」として知らせます）
- **FANBOX の支援金も売上に含めます**。取り込んだ月の売上として、手数料を引く前の金額を税込で数えます
- 年間の合計は **売上合計（税込）= 請求書 ＋ 支援金**。内訳として「うち請求書」「うち支援金」を並べます
  - 消費税 / 税抜 / 源泉徴収 / 入金済み / 未入金 は請求書だけの話なので、支援金とは混ぜずに「請求書の消費税」のように分けて出します
- **月別の推移を折れ線で表示**します。月をなぞると、その月の内訳が吹き出しで出ます
- 月別の内訳は、請求書ぶんと支援金ぶんを積んだ棒で見せます。その年の書類一覧（タップで書類へ）も出ます
- 名義で絞り込めます（アプリ全体の名義切り替えと連動）
- **請求書を売上として数え、請求書が1枚も無い案件だけ領収書を数えます**（請求書から起こした領収書の二重計上を避けるため）

#### 支援金（pixivFANBOX）

FANBOX の月ごとの支援金を取り込んで、請求書の売上と同じグラフに重ねられます。

- **取り込み方**：FANBOX の「支援金管理／振込」の画面を上から下までそのまま選んでコピーし、売上タブの **「表を貼り付けて取り込む」** に貼り付けるだけです。取り込む前に読み取り結果を一覧で確認できます
- FANBOX の画面は、年・月・金額がそれぞれ別の行に並びます。**「支援金」という見出しの次に来る金額だけ**を拾うので、手数料や小計は入りません。

  ```
  2026年
  8月
  支援金詳細
  支援金
  ¥500      ← これだけを拾う
  手数料
  ¥64
  小計
  ¥436
  ```

- **すでに入っている月は自動で除きます。** 毎月ページ全体をコピーして貼るだけでよく、同じ表を何度貼っても二重に増えません（増えた月だけが足されます）
  - 金額を入れ直したいときは、貼り付け画面の「すでに入っている月も入れ直す」を入にします
- 見出しが無い形（`2026年1月 ¥12,000` のように1行にまとまった表）でも読み取れます。その場合で金額の列が複数あるときは、どれを使うか選べます
- 1ヶ月ぶんだけ手で入れる・直すこともできます（同じ年月は置き換え）
- 名義を2つ以上登録しているときは、**支援金をどの名義の売上として数えるか**を選べます。選ばないうちは、案件と同じ考えでどの名義を見ていても数えます（取りこぼし防止）
- グラフは **「両方 / 請求書 / 支援金」** で切り替えられます。桁が違って片方が潰れるときに使ってください（軸は常に1本で、選んだ系列だけで目盛りを取り直します）

> **自動では取ってきません。** アプリはブラウザだけで動く静的サイトなので、
> 別サイトの中身を読むことはできません（CORS で止まります）。
> サーバー側で自動化するには FANBOX のログイン情報を預ける必要があり、
> 自動巡回は FANBOX の規約にも触れるおそれがあるため、貼り付ける方式にしています。

### 経理（下タブ）
下のタブの **「経理」** から開きます。いちばん上の **「事業 / 日常」** で帳簿を切り替えます。

| 帳簿 | 使いみち | 科目 |
|---|---|---|
| **事業** | 仕事の経費。案件・名義と結びつく | 印刷費・画材・消耗品・資料費・機材費・通信費・交通費・外注費・支払手数料・広告宣伝費・その他 |
| **日常** | ふだんの家計簿。案件・名義とは結びつけない | 食費・日用品・住居・水道光熱・通信費・交通費・医療・健康・趣味・娯楽・交際費・衣服・美容・教育・教養・保険・税金・社会保険・その他 |

- **記録する項目**：日付 / 金額 / 科目 / 支払先 / メモ（事業ではさらに 案件 / 名義）
  - 事業では **案件に紐づけられます**。印刷費をイベントの案件に付けておけば、その本にいくらかかったかが残ります
  - あとから **帳簿を事業↔日常に付け替えられます**（入力途中の内容も引き継ぎます）
- **レシートを撮って残す**：右下の＋、または「レシートを撮る」から。iPhone ではカメラが直接開きます（PCではファイル選択）
  - 撮った写真は**長辺1600px・JPEGに縮めてから**送ります（iPhoneの写真は1枚3〜4MBあるため。実測で 4.8MB → 264KB）
  - 写真は共有ファイルの **「経費レシート」（事業）/「日常レシート」（日常）** に分けて入り、PCとiPhoneの両方から見られます。一覧にはサムネイルが出ます
  - 写真を残すには同期の接続先が要ります。設定していないときは金額だけの記録になります
- 共通で **科目ごとの内訳**（割合つき。タップでその科目に絞り込み）と **月ごとの推移** が出ます
- **事業**：年間の 経費の合計 / 売上 / 差引 / 件数。「売上」と「差引」は売上タブと同じ数え方（請求書の発行済み＋支援金）で、名義の絞り込みにも従います
- **日常**：年間の 支出の合計 / 今月 / 1ヶ月の平均 / 件数。
  **1ヶ月の予算**を決めると、今月あといくら使えるかが帯で出ます（超えると赤くなります）

#### レシートの金額の読み取り
レシートを撮ったあと、入力画面の **「金額を読み取る」** を押すと、写真から金額の候補を拾って並べます。押した候補が金額欄に入ります。

- **勝手に入れず、候補を出して選ばせる作り**です。レシートは印字がかすれたり折れたりするので、読み違えたまま気づかず記録されるより、選んでもらうほうが確実だと考えました
- 「合計」「総計」「税込」「TOTAL」などの見出しがある行の金額を上に、次に金額の大きい順に並べます。小計・消費税・お預り・お釣り・ポイント・電話番号・日付・時刻は下げます
- **保存済みのレシート写真からも読み取れます**（撮り直し不要）
- 文字認識は **tesseract.js** を使います。アプリには同梱せず、**押したときだけ CDN から取りに行きます**（初回だけ英語の学習データ約2MBを取得。以後はブラウザが持つので2回目からは速い）
  - 日本語の学習データ（16MB）は使っていません。金額は半角数字なので英語の軽い版で足り、見出しは行の形と記号で拾えるためです
  - 通信できないときは「文字認識の部品を取りに行けませんでした。通信できる場所で試してください」と出ます。もともとレシート写真の保存には通信が要るので、読み取りだけ使えない場面はほとんどありません
  - 進み具合を帯で出し、**2分で打ち切ります**（黙って止まったままにならないように）

#### 固定費の登録
家賃・サーバー代・サブスクのように毎月同じ額が出るものを登録しておくと、毎月ぶんを1タップで記録できます。

- 登録する項目：帳簿 / 名前 / 金額 / 科目 / **毎月何日** / いつから
  - **31日など無い日は、その月の末日にまとめます**（2月なら28日・29日）
- 記録されていない月があると、経理タブの上に **「固定費が ◯件（◯ヶ月ぶん）まだ記録されていません」** と合計金額つきで出ます。「まとめて記録」でその月ぶんをまとめて作ります
- **同じ月を二重に作りません**。どこまで記録したかを固定費ごとに覚えていて、押し直しても増えません
- 記録した支出はふつうの支出と同じように直せます（金額が変わった月だけ直す、といった使い方ができます）
- 使わなくなったら「停止」にすると、以降は催促しなくなります（過去の記録は残ります）

#### CSV書き出し
年ごと・帳簿ごとに **CSV** に書き出せます（確定申告の集計や表計算ソフトに渡すため）。

- ファイル名は `METEO365_事業_2026.csv` / `METEO365_日常_2026.csv`
- 列は `日付 / 帳簿 / 科目 / 金額 / 支払先 / メモ / 案件 / 名義 / レシート / 固定費`
- **Excel でそのまま開けるように** BOM 付き UTF-8・改行 CRLF で出します。カンマや引用符を含む文字はきちんと囲みます
- 科目で絞り込んでいるときは、**画面に出ている絞り込みのまま**書き出します

### 請求漏れ・入金漏れの検知
ホームのアラートに、お金まわりの取りこぼしが出ます。

- **納品日を過ぎたのに請求書が1枚も無い仕事** → 「納品日から◯日、請求書がまだありません」（タップで書類画面へ）
- **発行済みのまま支払期限を過ぎている請求書** → 「入金予定日を◯日 過ぎています（金額）」（タップでその書類へ）
- アラートは重い順（危険 → 注意 → お知らせ）に並びます

### 取引先の登録
設定 →「取引先」から登録します。案件フォームの「取引先」欄でも、選択肢の中の「＋ 新しい取引先を登録」からその場で追加できます。

- 取引先名 / 敬称（御中・様）/ 担当者 / 郵便番号 / 住所 / 電話 / メール / 先方のインボイス登録番号 / メモ
- **書類の初期値**として、消費税（税抜・税込・非課税）、支払サイト（日数。0 なら翌月末）、源泉徴収の有無 を持たせられます
- 案件に取引先を紐づけると、その案件で作る請求書・領収書に **宛名・敬称・郵便番号・住所・支払期限・税区分・源泉徴収** が自動で入ります
- 書類の編集画面で取引先を選び直すと、その場で入れ直します
- 一覧には取引先ごとの **案件数・売上・未入金** が出ます
- 取引先を削除しても案件と書類は残り、紐付けだけが外れます（宛名の文字列はそのまま）

### 請求書・領収書（仕事の案件）
仕事の案件から、**請求書と領収書を作って印刷・PDF保存**できます。案件詳細の「請求書・領収書」カード、または案件一覧の仕事カードにある書類ボタンから開きます。

- **名義を複数登録でき、書類ごとに切り替えられます**。名義ごとに 代表者名 / 住所 / 電話 / メール / インボイス登録番号 / **ロゴ** / **印影** / 振込先 を持ちます（設定 → 名義）
- 案件の情報（取引先・報酬・タイトル）を引き継いで新規作成します
- 明細は何行でも追加でき、**税抜 / 税込 / 非課税** と **源泉徴収**（既定 10.21%）に対応します。消費税・源泉とも円未満は切り捨てです
- 「下書き → 発行済み → 入金済み」の状態を持ち、下書きから出すと **書類番号を自動採番**します（`INV-2026-0001` / `RCP-2026-0001`）
  - 連番は **種類 × 発行年ごと**で、年が変わると `0001` に戻ります。番号は「今日」ではなく **その書類の発行日の年**で決まります
  - バックアップを読み込んで既存の番号が入ってきた場合も、その年で使われている最大の番号の次から振り直すので重複しません
- **請求書から領収書をワンタップで起こせます**（但し書きを自動で用意）
- A4の書面をそのままプレビューし、「印刷 / PDF」から出力します。**iPhone では印刷画面の共有ボタンから「PDFとして保存」**できます

### 作業量の管理
- **1日の作業量の上限**を設定すると、合計が超える日をホームの警告・カレンダーの色で知らせます
- 完了した分の記録から **実績ペース（作業した日あたりの平均）** を算出し、必要ペースがそれを上回るタスクは強調表示します

### 印刷所の締切
- 1つのイベントに **早割・通常・割増** など複数の入稿プランを登録でき、それぞれの締切をカウントダウン表示
- 「開催日から◯日前」のプリセットボタンで逆算入力
- メインに指定したプランの締切が、タスクのゴール（自動スケジュールの終点）になります

### カレンダー / 予定表
カレンダーは **「案件」と「日常」の2つ**あり、上部の題名の右にある **切替ボタン（⇄）** で行き来します。中身は混ざりません。

| | 中身 |
|---|---|
| **案件** | 締切・入稿日・即売会・1日ごとのノルマ・休業日 |
| **日常** | 仕事と関係ない予定（通院・ゴミの日・誕生日・旅行・家賃の引き落としなど） |

- 切替ボタンは **1回押すともう一方に移り**、いま見ている側（`案件` / `日常`）を表示します
- ボタンが出るのは**カレンダーと日別の画面だけ**です（他の画面では効かないので出しません）
- **どちらを見ているかは端末ごと**に覚えます。iPhone で日常にしても、PC は案件のままです
- 日常のカレンダーは**緑**で示します（案件は青）

#### その日の勤務（出社 / リモートワーク / 泊まり勤務）
日別画面（日常）の **「この日の勤務」** から、その日の働き方をひとつ選びます。カレンダーのその日に色が付きます。

| | 色 |
|---|---|
| **出社** | 薄い黄色 |
| **リモートワーク** | 薄い赤 |
| **泊まり勤務** | 薄い青 |

- **1日にひとつだけ**です。別のものを押すと入れ替わり、**同じものをもう一度押すと外れます**
- 選んだボタンには、カレンダーに敷かれるのと同じ色が付くので、押す前に見た目が分かります
- **日常のカレンダーだけの機能**です（案件のカレンダーには出しません）
- **マスの地の色は「その日の勤務」だけの意味**にしています。予定があることは行そのもので分かるので、そこに別の色を重ねると勤務の3色に紛れて読み取れなくなるためです
- PC と iPhone で同期します。同期がぶつかって「統合する」を選んだときは、**まだ決めていない日だけ**相手の内容を取り込みます（既に入れた日は書き換えません）

#### 日常の予定
- 記録する項目：**予定名 / 日付 / 続く日数 / 時間 / 繰り返し / 色 / 重要 / メモ**
- **「重要」**にすると、**その日だけ**ホームのいちばん上（締切の警告と同じ欄）に、注意アイコン付きで出ます
  - 「締切まで◯日」と同じ見た目・同じ位置です。予定の当日にだけ出て、前後の日には出ません
  - ここにもチェックボックスが付きます。**押すとホームからだけ消えます**（下の「今日やること」からも同時に消えます。カレンダーには残ります）
  - 押し間違えても、カレンダーの日別画面からいつでも戻せます
- 色は **8色のはっきりした色**（あお・みずいろ・みどり・きいろ・オレンジ・あか・ピンク・むらさき）。上の勤務の薄い色を敷いた上に載るので、そこに埋もれないようにしてあります
- **終日**か、**開始・終了の時刻**を決めるかを選べます
- **続く日数**を2日以上にすると、旅行のように**またがる予定**になります（何日目かが出ます。月をまたいでも続きます）
- **繰り返し**：なし / 毎週 / 毎月 / 毎年。「いつまで」を決められます（空ならずっと）
  - 毎月31日など**その日が無い月は、月末に寄せます**（固定費と同じ考え方）
  - 毎年2月29日は、うるう年でない年は28日に出ます
  - 繰り返しは**1件だけ持って、表示のたびに広げます**（何百件にも増やしません）
- 追加は、カレンダー上部の **＋**、日別画面の **「予定を追加」**、または右下の丸ボタンから
- 予定をタップすると直せます。繰り返しの予定を消すと、繰り返している回もまとめて消えます
- 月名をタップすると、**その月の予定一覧**が日付ごとに並びます
- iPhone の狭いマスでは予定名を優先し、**時刻は日別の画面で**出します（PCの広いマスには時刻も並びます）
- 予定は同期で PC と iPhone に行き渡ります。同期がぶつかって「統合する」を選んだときも、**両方の予定を足し合わせます**

#### 案件のカレンダー
- 月表示：**画面いっぱいの月カレンダー**。各日のマスに、その日のタスク名とノルマ数、締切・イベントを **最大10件** 表示します（それを超えた分は「＋n」）
  - 予定が少ない月はこれまでどおり画面ぴったりに収まります。**10件近く入っている日がある月だけ、その行が伸びてカレンダーが縦にスクロール**します（1マスの高さは端末の画面に合わせて自動で決まります）
  - **左右にスワイプすると前後の月へ移動**します（‹ › ボタンでも移動できます）
  - **PC ではマウスホイールでも月を移せます**（下で次の月・上で前の月）。指で触れる端末では、慣性スクロールで何ヶ月も飛ばないよう付けていません
  - 上部の「YYYY年MM月」をタップすると、**その月の締切・イベント一覧**が開きます
  - **入稿日・締切日のマスはうっすら赤、即売会の当日はうっすら緑**に色を敷きます（両方ある日は緑）
- 日表示：その日のタスク一覧、進捗のワンタップ記録、その日を休みにする操作
- 休みにした日を開くと、日付の横に**「休業日」**の印が付き、ノルマ欄にも**「休業日」**と出ます
- 締切・ノルマ・休業日は案件だけのものなので、日常に切り替えているときは出しません（名義の絞り込みも出ません）
- ホーム：今日やること、遅れ・締切のアラート、これから7日間のノルマ、近い締切、案件ごとの進捗
  - **「今日やること」には、案件のノルマと日常の予定の両方**が並びます。日常の予定は **薄い水色**で敷いて `日常` の印を付けるので、ひと目で見分けられます。押すとその場で直せます
  - ホームは案件と日常の両方を見せる場所なので、**カレンダーの切替（案件／日常）には従いません**（どちらを見ていても両方出ます）
  - 日常の予定にも**案件と同じ位置にチェックボックス**が付きます。押すと **ホームの一覧からだけ消えます**
    - **カレンダーからは消しません。** 月のマスにも日別画面にも残ります
    - 押し間違えても、**カレンダーの日別画面から何度でも戻せます**。外した予定にはチェックが付いて `ホームから外し中` と出るので、もう一度押せばホームに戻ります
    - 繰り返しの予定は**日ごとに別もの**として扱います（今日のゴミ出しにチェックしても、来週の分は残ります）
  - **設定（歯車）はホームにだけ**出します。ほかのタブでは出しません（設定の画面では、行き場が分からなくならないよう出したままにしています）
- 案件詳細：ガントチャート（今日の位置と締切ラインつき）

### 自動スケジュール
開始日・締切日・予備日を指定すると、タスクの「重み」に応じて稼働日を配分し、各タスクの期間をまとめて割り当てます。

### そのほか
- 案件の検索・絞り込み（進行中 / 即売会 / 仕事 / 支援サイト / 完了）、完了・保管
  - **「進行中」には、作業開始日がまだ来ていない案件は出しません**（`開始前` として、種別のタブと「すべて」に出ます）
  - **種別のタブ（即売会・仕事・支援サイト）にも、完了した案件は混ざりません**。完了したものは「完了」タブで見ます
  - 完了した案件には残り日数（`◯日超過`）ではなく **`完了済`** と出ます
- JSON でバックアップの書き出し・読み込み
- **.ics 書き出し**（iPhone の標準カレンダーに締切やノルマを取り込めます）。**通知（前日／3日前／1週間前の9時）を付けられる**ので、アプリを開かなくても締切に気づけます
- ダークモード対応（端末の設定に追従）

### 画面の構成

- **設定は左上の「METEO365」の右にある歯車**から開きます（タブが6つで埋まったため、下のタブからは外しました）。**歯車はホームにだけ**出します（ほかのタブでは邪魔になるため）

## データについて

### 保存場所（IndexedDB）
- データの本体は **端末のブラウザ内の IndexedDB** に保存されます。**既定では外部に一切送信しません**。
  - 同期を設定したときだけ、**自分で立てた Cloudflare** にデータとファイルを預けます。第三者のサーバーは経由しません。
- localStorage には**控え**を同時に書きます。IndexedDB が使えない環境ではこの控えが本体になります。
  - 起動時に両方の `savedAt` を比べ、**新しいほうを採用**します。書き込みが終わる前にアプリを閉じても取りこぼしません。
  - 控えが 5MB に収まらないときはロゴ・印影を落として保存し、復帰時に IndexedDB 側から画像を補います。
- IndexedDB へ移したことで、**ロゴ・印影・書類の枚数が増えても容量で詰まりません**（設定画面に使用量が出ます）。
- 起動時にブラウザへ **データを消さないよう申請**します（対応状況は設定画面に表示されます）。

### 端末内の自動バックアップ
- **1日1回、日付が変わったあと最初にアプリを開いたときに、自動で控えを取ります**（設定 → 自動バックアップ）。
- 残す世代数を指定でき、古い自動ぶんから消えます。手動の控えと「読み込み前 / 全削除前 / 復元前」の控えは消えません。
- 「控えの一覧から戻す」で任意の時点に戻せます。**戻す直前の状態も控えとして残る**ので、戻しすぎてもやり直せます。
- これは端末内の話なので、**端末そのものを失うと一緒に消えます**。下の iCloud への書き出しと併用してください。

### iCloud へのバックアップ

まず前提として、**iOS の Web アプリからは iCloud へ直接・自動で書き込めません**。バックグラウンド実行（Periodic Background Sync）もファイルシステムへの直接アクセスも iOS Safari では使えないためです。
そこで「端末内は完全自動」「iCloud へはワンタップ」という形にしています。

**1. 保存先を一度だけ設定する**

1. iPhone の「ファイル」アプリで、iCloud Drive に **「案件ポータルバックアップ」** フォルダを作る
2. 「設定」→「Safari」→「ダウンロード」→「その他…」を開き、いま作ったフォルダを選ぶ

以降、アプリの **「iCloud に書き出す」** を押すだけで、そのフォルダに `案件ポータル-YYYY-MM-DD.json` が入ります。
別の場所へ入れたいときは「保存先を選んで書き出す」（共有シート →「"ファイル"に保存」）を使ってください。

**2. 普段は表示しません**

日々のバックアップは Cloudflare の同期でまかなうので、**ホームに書き出しの案内は出しません**。
iCloud への書き出しは Cloudflare 側で予期しないことが起きたときの備えとして残してあり、使うときは **設定 →「iCloud への書き出し」** から実行します。最後に書き出した日も同じ場所に出ます。

**3. 0時ごろに自動で走らせたい場合（任意）**

iPhone の「ショートカット」アプリでオートメーションを作ると、**端末内の自動バックアップまでは無人**で回せます。

1. ショートカット →「オートメーション」→「＋」→「時刻」→ **午前0:00**、「毎日」
2. 「即時実行」にして「実行前に尋ねる」をオフ
3. アクションに「**Appを開く**」を追加し、ホーム画面に追加した本アプリを選ぶ

これで0時にアプリが開き、その瞬間に端末内の世代バックアップが取られます。**iCloud への書き出しだけは、この方法でも自動化できません**（ファイルの書き出しにユーザー操作が要るため）。必要なときに設定画面から1タップしてください。

**完全に無人で0時にクラウドへ置きたい場合** は、書き込み先のサーバー（自前のAPI、あるいは Dropbox / Google Drive のような OAuth 対応ストレージ）が必要になります。その場合は iCloud ではなくそのサービスが保存先になります。必要になったら言ってください。

### 書き出し・読み込み
- 読み込み画面で、**ファイルとこの端末のどちらが新しいか**を保存日時で突き合わせて表示します。古いファイルで上書きしそうなときは警告を出します。
- **「統合（無いものだけ追加）」** は、いま無い **案件・名義・取引先** を足します。既にあるものの中身は書き換えません。書類番号の連番は両方の大きいほうを採ります。
- **「全て置き換え」** はファイルの内容でそっくり入れ替えます。
- どちらも実行前の状態が控えとして残るので、取り違えても戻せます。
- 書き出したファイルはただの JSON なので、PC でも中身を確認できます。

## PC と iPhone でデータを共有する

方法は2つあります。**自動同期**（同期サーバーを立てる）と、**ファイルの受け渡し**（サーバー不要）です。

### A. 自動同期（推奨）

自分で小さな置き場をひとつ立てて、アプリが自動で送受信します。立てかたは **[sync/README.md](sync/README.md)** にあります（Cloudflare Workers・無料枠・10分ほど）。

つないだあとは、次のタイミングで自動的に揃います。

- アプリを開いたとき（もう片方の端末での変更を取り込む）
- **下のタブを移ったとき**（ホーム・カレンダー・案件・ファイル・設定の行き来）
- アプリを閉じる・別のアプリに切り替えるとき
- 編集して8秒ほど経ったとき

タブ移動での同期は、**この端末に未送信の変更があれば必ず送ります**。変更が無いときは受け取りのために走りますが、タブを行き来するたびに叩かないよう**8秒の間隔**をあけます。

画面右上の**同期ボタン**からいつでも手動で実行できます（未送信の変更があると青い点が付きます）。設定 →「PC・iPhone の同期」の「いま同期」も同じ動作です。

**ぶつかったとき**：前回の同期のあと両方で変更があった場合は、黙って上書きせずに聞きます。

| 選択肢 | 何が起きるか |
| --- | --- |
| **統合する** | どちらにも無いものを足し合わせる（既存の中身は書き換えない）。ふだんはこれ |
| この端末を残す | サーバーをこの端末の内容で置き換える |
| サーバーを残す | この端末をサーバーの内容で置き換える |

どれを選んでも直前の状態は控えとして残ります。

**送らないもの**：接続先・合鍵・最後に書き出した日・いま選んでいる名義は**端末ごとの設定**として扱い、同期の中身に含めません。片方の合鍵がもう片方へ流れることはありません。

**注意**：Cloudflare KV は書き込みが行き渡るまで最大60秒ほどかかります。片方で保存した直後にもう片方を開くと古い内容が見えることがあるので、少し待って「いま同期」を押してください。

## ファイル共有（「ファイル」タブ）

同期サーバーに R2（ファイル置き場）を足すと、**PC と iPhone で同じファイルを見られる**ようになります。設定は [sync/README.md](sync/README.md) の「4.5 ファイル共有を使う場合」にあります。

「ファイル」アプリのように、**フォルダとファイルを同じ並びで一覧**します（iPhoneで3列、PCでは幅に応じて増えます）。

- **アップロード**：右下の**＋ボタン**。複数まとめて選べます。PCでは**画面のどこにでもドラッグ＆ドロップ**できます
- **ダウンロード**：タイルをタップ
- **その他の操作**：タイル右上の「⋯」から（保存 / フォルダを移す / 案件に紐づける / 削除）
- 上げた端末の名前（iPhone / Windows）が並ぶので、どちらから入れたか分かります
- **タブを開くたびに一覧を取り直します**。もう片方の端末が上げたファイルもすぐ出ます

### サムネイル

画像は**中身をそのままタイルに出します**。ただし通信量が増えないよう、次の条件を付けています。

- **2MBまでの画像だけ**。それより大きいものと画像以外は、これまでどおり種類のアイコンです
- **画面に入ったものだけ**取りに行きます（少し手前から先読み）。下の方にあるものは、スクロールするまで通信しません
- 取ってきた画像は**その画面を開いている間だけ**覚えます。他のタブへ移ると捨てるので、端末の容量は使いません

### フォルダ

- 右上の**「フォルダを作る」**でいつでも作れます。作ったフォルダは**同期で両方の端末に出ます**
- **フォルダの中にもフォルダを作れます**（階層の深さに制限はありません）。フォルダを開いた状態で同じボタンを押すと、その中にできます
- フォルダを開いてから＋を押すと、そのフォルダに入ります
- フォルダを開いているときに**下の「ファイル」タブをもう一度押すと、ひとつ上の階層に戻ります**。押すたびに1階層ずつ上がり、いちばん上まで来たら、それ以上押しても画面はそのままです
- ファイルの「⋯」→**フォルダを移す**で移動できます。**ファイルを入れ直さないので、大きくても一瞬で終わります**
- フォルダの「⋯」から**名前の変更**と**削除**ができます。中身があるフォルダを消すときは、
  **「フォルダだけ削除（ファイルは残る）」**か**「中のファイルごと削除」**かを選べます（下の階層もまとめて対象になります）
- どのフォルダにも入れていないファイルは、フォルダと並んでそのまま置かれます

### フォルダごとドラッグ＆ドロップ（PC）

エクスプローラーからフォルダをそのまま画面に落とせます。**中の階層をそのまま作って**、ファイルを入れていきます。
以前はフォルダを落とすとエラーになっていました（ブラウザがフォルダを中身0バイトのファイルとして渡すため）。いまは中を辿って本当のファイルだけを送ります。

> **仕組みの補足**：フォルダの割り当ては**アプリ側のデータ**に持たせ、同期でやり取りしています。
> R2 はメタ情報だけの書き換えができないため、そこに持たせるとフォルダを移すたびに
> ファイルを丸ごと入れ直すことになるためです。おかげで移動は一瞬で終わります。
>
> ただしそれだけだと、**片方の端末で入れたファイルが、もう片方ではいちばん上に出てしまう**ことがありました。
> ファイル自体（R2）と設定（KV）は別々に届くので、ファイルが先に見えて割り当てが後から来るためです。
> そこで**置いたときのフォルダのパスを R2 側にも残す**ようにしました。まだ設定を受け取っていない端末は、
> このパスから同じ階層を組み立てて表示します。移動したあとの場所はアプリ側のデータが優先されるので、
> 「いちばん上へ移す」がパスの記録で元に戻されることはありません。

### 手元へのバックアップ

サーバーだけに置きっぱなしにしないための機能です。

「手元にバックアップ」→ **すべてZIPで保存** で、サーバー上のファイルを**1つのZIPにまとめてダウンロード**します。標準のエクスプローラーでそのまま開ける普通のZIPです（日本語のファイル名も保持します）。**フォルダ分けもそのまま再現します**。

PC で実行して、外付けやローカルに残しておくのが安全です。合計 300MB を超えるときは、ZIPを作る間そのぶんメモリを使うため確認を挟みます（iPhone では途中で止まることがあります）。

### 制限

- **1ファイル100MBまで**。Workers の受信上限（無料・Proプラン）によるもので、R2 側の制限ではありません。PSD などの大きな制作データは分割するか、R2 のダッシュボードから直接入れてください
- 無料枠は 10GB 保存・転送量無料。超えた分は $0.015/GB・月です

### B. ファイルの受け渡し（サーバー不要）

同期サーバーを立てない場合は、**JSON ファイルを iCloud Drive 経由**で渡します。

### 手順

1. **新しいほうの端末**で 設定 →「iCloud に書き出す」（保存先は「案件ポータルバックアップ」フォルダ）
2. **もう一方の端末**でそのファイルを開く
   - Mac：Finder の iCloud Drive、Windows：「iCloud for Windows」を入れると同じフォルダがエクスプローラーに出ます
3. 設定 →「バックアップを読み込む」でそのファイルを選ぶ
4. 画面に出る**日時の突き合わせ**を見て、「統合」か「全て置き換え」を選ぶ

### 使い分け

| やりたいこと | 選ぶもの |
| --- | --- |
| 片方でしか編集していない → もう片方に丸ごと持っていく | **全て置き換え** |
| 両方で別々に案件や取引先を足した → 合流させたい | **統合** |

### 気をつけること

- **同じ案件を両方の端末で編集すると、あとから読み込んだほうの内容が勝ちます。** 統合は「無いものを足す」だけで、既存の中身は突き合わせません。
- そのため、**編集する端末はなるべく片方に寄せて**ください。iPhone を主、PC を従（見るだけ・たまに入力）にするのが安全です。
- 取り違えても、読み込み前の状態は控えとして残っています（設定 → 自動バックアップ →「控えの一覧から戻す」）。

この方法は手作業なので、**編集する端末はなるべく片方に寄せて**ください。自動で揃えたいなら A の同期サーバーを立てるのが確実です。

## アプリのアイコンを差し替える

1. 使いたい画像を **`assets/app-icon.png`**（.jpg / .webp も可）としてリポジトリに置く
2. `python3 tools/make-icons.py` を実行する（`pip install pillow` が必要）

ホーム画面用・PWA用・タブ用のPNGが一度に作り直されます。
iPhone は**ホーム画面に追加した時点のアイコンを保持する**ため、差し替え後は一度ホーム画面から削除して追加し直してください。

## プロトタイプでの制限

- 端末へのプッシュ通知は行いません（iOS の Web アプリでは制限があるため）。締切が近い案件はアプリ内のアラートと、.ics 書き出し＋標準カレンダーの通知で代替してください。
- 複数端末での同期は、自分で同期サーバーを立てたときだけ使えます（[sync/README.md](sync/README.md)）。立てない場合は JSON の書き出し／読み込みで受け渡してください。
- **iCloud への書き出しは無人化できません**。端末内の自動バックアップは無人ですが、ファイルとして iCloud へ出す部分は1タップ必要です（理由は「iCloud へのバックアップ」を参照）。
- 日本の祝日は自動では入りません（カレンダーの日別画面から休業日として個別に登録できます）。
