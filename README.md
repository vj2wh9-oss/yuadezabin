# 締切カレンダー（プロトタイプ）

即売会イベント・印刷所の入稿締切・イラストの仕事の納期を **ひとつのカレンダーで** 管理する、個人用のウェブアプリです。
iPhone での利用を第一に設計しています（ビルド不要・オフライン動作・データは端末内に保存）。

## できること

### 案件の管理
- **即売会**（イベント日・会場・スペース・印刷所の入稿締切）と **仕事**（クライアント・納品日・報酬）を同じ画面で管理
- 案件ごとに **漫画 / イラスト** を選ぶと、対応する基本タスクが自動で作られます
  - 漫画：プロット → ネーム → 下書き → 線画 → 仕上げ
  - イラスト：ラフ → 下書き → 線画 → 下塗り → 塗り → 仕上げ
- タスクは自由に追加・削除・並べ替え・リネームでき、テンプレート自体も設定画面で編集できます

### 1日ごとのノルマ自動計算（このアプリの中心機能）
合計ページ数（またはカット数）と作業期間を指定すると、**1日あたりのノルマを自動で割り振ります**。

> 例）合計30ページの漫画で「下書きを 5/12〜5/20 にやる」と設定
> → 9日間に 3P / 3P / 4P / 3P / 3P / 4P / 3P / 3P / 4P（合計30P）と自動配分

- 「作業しない曜日」や「休業日」に設定した日は自動的に飛ばして、残りの日に配り直します
- 特定の日のノルマは手で固定でき、その差分は他の日へ自動で再配分されます
- 実績を記録すると **遅れ量** と **これから必要な1日あたりのペース** を表示します
- 「残りを再配分」で、遅れたぶんを今日以降にならし直せます

### 印刷所の締切
- 1つのイベントに **早割・通常・割増** など複数の入稿プランを登録でき、それぞれの締切をカウントダウン表示
- 「開催日から◯日前」のプリセットボタンで逆算入力
- メインに指定したプランの締切が、タスクのゴール（自動スケジュールの終点）になります

### カレンダー / 予定表
- 月表示：その日のノルマ合計・締切・イベントをひと目で確認
- 日表示：その日のタスク一覧、進捗のワンタップ記録、その日を休みにする操作
- ホーム：今日やること、遅れ・締切のアラート、これから7日間のノルマ、近い締切、案件ごとの進捗
- 案件詳細：ガントチャート（今日の位置と締切ラインつき）

### 自動スケジュール
開始日・締切日・予備日を指定すると、タスクの「重み」に応じて稼働日を配分し、各タスクの期間をまとめて割り当てます。

### そのほか
- 案件の検索・絞り込み（進行中 / 即売会 / 仕事 / 完了）、完了・保管
- JSON でバックアップの書き出し・読み込み
- **.ics 書き出し**（iPhone の標準カレンダーに締切やノルマを取り込めます）
- ダークモード対応（端末の設定に追従）

## 使い方

### iPhone で使う
1. このリポジトリを GitHub Pages などの HTTPS で公開します
   （リポジトリの Settings → Pages → Branch にこのブランチを指定するだけで動きます）
2. Safari で開き、共有ボタン →「**ホーム画面に追加**」
3. アプリのように全画面で起動し、オフラインでも動作します

### 手元で試す
静的ファイルのみなので、適当なサーバーで開くだけです。

```sh
npx http-server -p 8777 .
# → http://localhost:8777/index.html
```

`index.html` をブラウザで直接開いても動作します（Service Worker だけは HTTPS 環境でのみ有効）。
最初に「サンプルデータを入れて試す」（案件タブ／設定タブ）を押すと、動きを確認できます。

## データについて

- データは **端末のブラウザ内（localStorage）にのみ** 保存されます。サーバーには何も送信しません。
- 履歴の削除や機種変更で消えるため、設定画面から **ときどき JSON バックアップを書き出して** ください。

## 構成

```
index.html               画面の骨組み
manifest.webmanifest     ホーム画面追加（PWA）用
sw.js                    オフラインキャッシュ
assets/style.css         スタイル（iPhone 優先・ダークモード対応）
assets/icon-*.png|svg    アイコン
js/util.js               日付・DOM のユーティリティ
js/store.js              データ保存（localStorage）と CRUD
js/schedule.js           稼働日・ノルマ配分・進捗・自動スケジュール・ICS 生成
js/ui.js                 共通UI部品（ボトムシート・トースト・入力部品）
js/forms.js              案件／タスク／進捗の入力フォーム
js/view-*.js             各画面（ホーム・カレンダー・案件一覧・詳細・設定）
js/app.js                ルーティングと全体制御
```

## プロトタイプでの制限

- 端末へのプッシュ通知は行いません（iOS の Web アプリでは制限があるため）。締切が近い案件はアプリ内のアラートと、.ics 書き出し＋標準カレンダーの通知で代替してください。
- 複数端末での同期はありません（JSON の書き出し／読み込みで移行してください）。
- 日本の祝日は自動では入りません（設定画面で休業日として個別に登録できます）。
