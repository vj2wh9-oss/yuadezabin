# だてメテオ －イベント当日用－

即売会の当日、会場で在庫を数えるための小さなサイト。
[METEO365](https://vj2wh9-oss.github.io/yuadezabin/)（締切管理アプリ）の
即売会チケットを、そのまま会場で開く。

- 公開先 … https://vj2wh9-oss.github.io/torani/
- 素の HTML・CSS・JS。ビルドは無い（METEO365 と同じ作り）

## 使いかた

1. METEO365 の **設定 →「イベント当日用サイト」** で合鍵を作る
2. そこに出る URL を、会場で使う端末で開く
   （合鍵と接続先は端末に控えるので、2回目からは URL だけで開ける）
3. トップでイベントを選ぶ
4. 頒布物が並ぶ。会場で足す／隠すができる
5. 終わったら在庫を数えて入れ、**「在庫締め」** を押す
6. METEO365 のそのチケットの画面で **「届いているか見る」→「取り込む」**

取り込むと、チケットの「持ち帰り」の数として入る。
そこから先（販売数・売上・在庫から引く）は、これまでどおり
METEO365 のチケットの「集計」で決める。

```
持ち込み − 在庫（持ち帰り） ＝ 頒布数
```

## 画面

- **トップ** … 即売会のチケットの一覧。画像付き。当日のものは緑で縁取る
- **頒布物** … 持込／在庫／頒布。数えるそばから頒布数と売上が出る
  - 「足す」… METEO365 に登録してある頒布物から選んで足す
  - 目のボタン … その行を隠す（下の「隠したもの」から戻せる）
- **在庫締め** … 下に貼り付く。数えながらでも、いつでも押せる

数えかけの数は端末に控えるので、電波が切れても閉じても消えない。
締めたあとに片づく。

## 合鍵のこと

このサイトが持っているのは、**このサイト専用の合鍵（32桁）だけ**。
それでできるのは次の3つで、ほかの持ちものには手が届かない。

- 即売会のチケットの一覧を読む
- そのチケットに持っていく頒布物を読む
- 数えた在庫を預ける

METEO365 本体の合鍵（読み書き全部）は、こちらには渡ってこない。
会場の端末を手放すときは、METEO365 の設定から合鍵を**捨てる**か
**作り直す**と、その URL はもう通らなくなる。

## 置き場所

GitHub Pages（このリポジトリの `main`）。
サーバー側の受け口は METEO365 と同じ Cloudflare Worker にある
（`/v1/event/...`）。Worker のコードは
[yuadezabin の `sync/worker.js`](https://github.com/vj2wh9-oss/yuadezabin/blob/main/sync/worker.js)。

## 中身

```
index.html
assets/style.css      METEO365 と同じ組み（青系・角丸は最小限）
assets/icon.svg
js/util.js            小さな道具（el / 日付 / 円）
js/icons.js           絵
js/ui.js              ボタン・チップ・シート・知らせ
js/api.js             Worker とのやりとり（合鍵はここだけが持つ）
js/store.js           いま画面が持っているもの＋手元の控え
js/view-events.js     トップ（イベントを選ぶ）
js/view-items.js      頒布物と在庫締め
js/app.js             つなぎ
```
